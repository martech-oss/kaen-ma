# Measurement Guide

Use one outcome metric and one early signal.

| Motion       | Outcome metric examples                      | Early signal examples                       |
| ------------ | -------------------------------------------- | ------------------------------------------- |
| Acquisition  | Qualified contact rate, form completion rate | Form starts, consent completion             |
| Onboarding   | Activation rate, time to first value         | First key event, setup completion           |
| Engagement   | Meaningful repeat action, feature adoption   | Message click, next-step start              |
| Retention    | Retained usage, churn-risk recovery          | Return visit, risk score movement           |
| Reactivation | Reactivated contact rate                     | Re-entry click, renewed activity            |
| Measurement  | Decision-grade event coverage                | Valid event receipt, dashboard completeness |

Rules:

- State the event or field that proves each metric.
- Use an existing baseline when supplied; otherwise mark the baseline as unknown.
- Define the minimum change that warrants continuing the flow.
- Pick a review point based on the expected lifecycle delay, not an arbitrary reporting cadence.
- Record opt-outs, suppression, delivery failures, and missing events as first-class outcomes.
