# Routing Guide

Choose the motion that owns the next decision, even when the request mentions several channels.

| Situation                                             | Primary motion | Typical next artifact            |
| ----------------------------------------------------- | -------------- | -------------------------------- |
| Unknown visitors need a reason to identify themselves | Acquisition    | Capture and qualification brief  |
| New contacts need to reach first value                | Onboarding     | Activation flow brief            |
| Active contacts need a useful next action             | Engagement     | Behavior-triggered nurture brief |
| Usage or intent is declining                          | Retention      | Risk intervention brief          |
| Inactive contacts may still have value                | Reactivation   | Re-entry experiment brief        |
| The team cannot tell what works                       | Measurement    | Event and readout brief          |

Tie-breakers:

1. Prefer the earliest lifecycle bottleneck supported by evidence.
2. Prefer a behavior or consent signal over a guessed demographic trait.
3. Prefer one audience and one entry trigger over a catch-all journey.
4. Route to `customer-journey-map` when the bottleneck itself is not yet known.
